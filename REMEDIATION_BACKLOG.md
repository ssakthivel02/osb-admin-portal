## Completion definition

The portal may be labelled production-ready only after:

- all required CI commands pass;
- critical Playwright workflows pass;
- no placeholder or hardcoded production data remains;
- Dataset B has no public read or publication path;
- promotion and publication use approved backend controls;
- source provenance is visible for every publishable record;
- no unresolved critical security issue exists.
